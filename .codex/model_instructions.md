# Инструкции для Codex (repo-scoped)

Ты работаешь в spec-first репозитории.

- Предпочитай маленькие, reviewable diffs.
- Не выдумывай контракты. Следуй `schemas/taskresult.schema.json` и `docs/spec/*`.
- Если нужна крупная зависимость — сначала ADR.
- Держи изменения детерминированными и local-first.
- Обновляй документацию и тесты/фикстуры вместе с кодом.

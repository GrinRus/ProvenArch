# Политика документации

## Язык
- Primary язык документов: **RU** (для стейкхолдеров и инженерных лидов).
- Если нужен EN — добавляем отдельные файлы `*.en.md`.
- Не “переписываем” RU в EN без архивации предыдущей версии.

## Не терять контент
- Если документ становится слишком большим — выносим детали в `docs/spec/*` или отдельные файлы,
  а в исходном документе оставляем ссылки.
- Любые крупные сокращения фиксируем:
  - либо в `docs/reviews/*`,
  - либо через явный комментарий/ссылку на commit в Git-истории.

## Версионирование
- Stakeholder doc: версия в заголовке (v0.x)
- README: статус (baseline / implemented) + дата последней ревизии

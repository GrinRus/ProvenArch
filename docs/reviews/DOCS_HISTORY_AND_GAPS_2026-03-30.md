# Анализ истории документов и потерь контента (2026-03-30)

## Что случилось
1) Изначально был подготовлен подробный RU документ для стейкхолдеров (v0.2) + основополагающий README (технический контракт).
2) Затем мы приняли стек реализации **Go (Option B)** и начали собирать репозиторий-скелет.
3) В процессе перехода к “strict baseline” (без кода) были сделаны 2 изменения, которые привели к проблеме:
   - документы были **сильно сокращены** (часть секций исчезла),
   - основной язык документов **переключился на EN**.

## Какие секции потерялись (по сути)
В упрощённой версии stakeholder doc и README исчезли или стали сильно менее детальными:
- “Проблема и почему важно” (pain points + почему диаграммы не работают)
- детальная операционная логика runtime (subagents/skills/constitution)
- подробный init pipeline (inputs/actions/outputs по шагам 1–4)
- регулярный цикл (manual MVP + future)
- Git workflow (что версионируем, как ветвимся)
- сравнение вариантов хранения модели и выбор entity-per-file (с аргументацией)
- roadmap (MVP → Wave 1 → Wave N)
- открытые вопросы с критичностью (структурированный список)
- расширенный appendix с вариантами организации docs/workspace

## Почему это произошло
- Мы “переписали” документы в стиле репозитория‑скелета, сделав упор на структуру,
  и случайно потеряли продуктовый “мясной” слой, который нужен стейкхолдерам и лидерам.
- Параллельно писали новую версию быстрее, и язык сменился на EN.

## Как мы это исправили в текущем baseline
- Восстановили **RU** версии `docs/STAKEHOLDER_DOC.md` и `README.md`, используя исходные тексты как основу.
- Сохранили исторический контекст в Git-истории и review-документах для прозрачности.
- Перевели ключевые spec документы `docs/spec/*` и базовые инструкции (AGENTS/CONTRIBUTING) на RU, чтобы репо читался цельно.

## Дальше (guardrails)
Рекомендуем:
- держать RU как primary язык для верхнеуровневых документов,
- если нужен EN — добавлять отдельные файлы `*.en.md`,
- любые сокращения делать через **вынесение в отдельные spec файлы**, а не удаление.

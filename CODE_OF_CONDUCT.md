# Code of Conduct

## Our standard

The ProvenArch project expects professional, respectful collaboration in issues, pull requests, discussions, reviews, and maintainer spaces.

Examples of welcome behavior:
- focus on technical evidence and user impact;
- give actionable feedback;
- respect different experience levels and communication styles;
- disclose conflicts of interest when relevant.

Unacceptable behavior includes harassment, threats, discriminatory language, sexualized comments, deliberate intimidation, doxxing, spam, and sustained disruption of project work.

## Enforcement

Maintainers may remove comments, close discussions, restrict participation, or block users when behavior harms the project or its contributors.

Report conduct concerns privately to a maintainer. Security vulnerabilities must follow [SECURITY.md](SECURITY.md), not public issues.

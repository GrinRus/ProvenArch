# ui/

UI bootstrap shell: React + TypeScript + Vite.

Bootstrap slice уже содержит buildable shell и local dev/test scripts.

Основные команды:
- `npm ci --prefix ui`
- `npm run dev --prefix ui`
- `npm run typecheck --prefix ui`
- `npm run test --prefix ui -- --run`
- `npm run build --prefix ui`

См. [README.md](../README.md) и `docs/spec/PIPELINE_SPEC.md` для продуктовых ожиданий.

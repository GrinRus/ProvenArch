# internal/

Внутренние модули реализации ACP.

Текущий baseline включает рабочие модули:
- `internal/workspace`
- `internal/orchestrator`
- `internal/runtime/claudecode`
- `internal/model`
- `internal/reports`
- `internal/api`

Дальнейшие slices расширяют глубину семантики и production-hardening, но базовый local-first execution path уже исполним.
